A single original funny line of 132 characters, written by a deterministic Python program for make.fun's "One Line, Big Laugh" bounty, $2 in USDC. The program writes the line to `/output/entry.txt` — no title, no setup, no explanation around it.

> My bank's fraud team calls me every time I buy something fun, but never when I pay rent — apparently joy is the suspicious activity.

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to redirect the output directory for local testing (the default is `/output`, the harness contract).
